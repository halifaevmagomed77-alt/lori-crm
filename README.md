# Lori CRM

CRM свадебного салона Lori: примерки, клиентки, продажа и аренда платьев, отчёты для владельца.

Сейчас это **прототип**: данные вымышленные и хранятся в браузере (localStorage). Кнопка «Сбросить демо-данные» в меню возвращает исходный набор.

## Разделы

- **Сегодня** — примерки дня (отметить «пришла / не пришла», сразу оформить продажу или аренду), платья к выдаче и возвраты из аренды на 3 дня вперёд.
- **Календарь** — неделя примерок, выдач и возвратов.
- **Клиентки** — база с поиском и этапами: новая заявка → была на примерке → оформлена сделка → платье выдано.
- **Платья** — модели коллекции с ценами продажи и аренды, статус образца (в салоне / забронирован / в аренде), проверка пересечений аренды.
- **Отчёты** (только владелец) — примерки, продажи, аренда и конверсия за любой период, сравнение с прошлым периодом, популярные платья, источники клиенток.

Роли: владелец видит всё, администратор — всё, кроме отчётов.

## Запуск

```bash
npm install
npm run dev
```
