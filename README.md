# Lori CRM

CRM свадебного салона Lori — электронная версия бумажного журнала салона. Платья только сдаются в прокат.

Сейчас это **прототип**: данные вымышленные и хранятся в браузере. На экране входа можно выбрать любую учётную запись и сбросить демо-данные.

## Роли

| | Владелец (1) | Администратор (1) | Консультант (до 30) |
|---|---|---|---|
| Журнал дня, визиты, запись (договор на залог) | ✓ | ✓ | ✓ |
| Выдача, приёмка, отказ, правка чужих записей | ✓ | ✓ | — |
| Химчистка, сотрудники и табель | ✓ | ✓ | — |
| Подтверждение получения оплат | ✓ | — | — |
| Финансовые отчёты, поставщики, закупочные цены | ✓ | — | — |

## Разделы

- **Журнал** — страница дня как в тетради: табель (пришла / ушла), строки «Зашли, Примерка, Возвратные, Запись, Отказ, Выдача, Приёмка, Химчистка, Штрафы кл.», итог по консультантам «встретила / записала, %». Листается по дням.
- **Невесты** — база; возвратная невеста определяется автоматически и закрепляется за своим консультантом.
- **Записи** — договоры с фильтрами по периоду, статусу, консультанту, названию платья и сумме проката. Режим «Книжка» листает записи по одной, как страницы тетради.
- **Платья** — экземпляры: одна модель может быть от разных поставщиков. Поставщики и закупка видны только владельцу.
- **Химчистка** — что сейчас в химчистке и сколько ушло за период по моделям.
- **Сотрудники** — учётки, смены, процент записи.
- **Отчёты** (владелец) — воронка в процентах, консультанты, модели, отказы с суммой и залогами, штрафы отдельной строкой, деньги и неподтверждённые оплаты, поставщики и «у кого выгоднее брать».

## Запуск

```bash
npm install
npm run dev
```

## Рабочая версия

База PostgreSQL на российском сервере (152-ФЗ, паспортные данные), вход по телефону, загрузка фото платьев, печать договоров на залог и аренду из записи.
